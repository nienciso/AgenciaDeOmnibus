# AgenciaDeOmnibus
- Proyecto final Bios 1er año -

Se desea realizar el desarrollo de un sistema de promoción de paquetes de viajes terrestres para 
una agencia de turismo (empresa que gestiona la información a publicar para sus promociones). Se trabaja de forma conectada ADO.NET para el manejo de la información de la base de datos y a través del uso exclusivo de procedimientos almacenado. Proyecto realizado en C# con tecnologias .NET y Base de datos SQL Server utilizando Stored Procedures.
